# План реализации

1. **Технический spike**: проверить Vanessa Runner 3.x, EDT CLI, 1С, сборку CF, загрузку CF в одноразовую тестовую ИБ и точные параметры команд.
2. **ProcessRunner и Tool Providers**: безопасный запуск CLI, логи, timeout, cancellation, тесты.
3. **Pipeline Engine**: YAML schema, registry, expressions, состояния, snapshot планов, unit tests.
4. **Agent Worker**: регистрация, capabilities, polling, lease, heartbeat, отчётность.
5. **Deploy**: создание ИБ, SQL backup, блокировка сеансов, LoadCfg, UpdateDBCfg, verify, recovery.
6. **Backend API + SQL schema**: проекты, базы, задания, блокировки, артефакты, аудит; заявки на тестовые базы, владельцы, шаблоны, квоты и резервирование ресурсов.
7. **Заказ тестовых баз (обязательная часть MVP)**: создание пустой ИБ и восстановление опубликованного SQL-шаблона в новую БД, изоляция, проверка, выдача доступа, продление, удаление и lifecycle worker. Выбор ветки/готового CF подключить после готовности сборки и deploy.
8. **React UI**: «Заказать базу», «Мои базы», прогресс, подключение, срок использования, продление и удаление; существующий запуск сборки/развёртывания.
9. **Интеграционные тесты заказов**: критерии из test-environments.md, включая idempotency, конкурентные квоты, изоляцию и потерю агента.
10. **Интеграционные тесты**: повтор после сбоя, потеря агента, ошибка backup, ошибка UpdateDBCfg, concurrent deployment.

## Вопросы перед кодированием
- Точные версии EDT, 1С и Vanessa Runner.
- Доступность RAS и схема сервисных учётных записей.
- Где хранятся CF и SQL backups, retention policy.
- Источники опубликованных SQL-шаблонов, разрешённые проекты, частота обновления и обязательный профиль подготовки. Пустая база и восстановление из шаблона включены в MVP.
- Политика завершения пользовательских сеансов.
- Период запуска reconciliation и lifecycle worker; стартовые квоты, сроки и политика удаления просроченных баз.
