Учётные данные целевого контура

Хранилище по умолчанию отключено. Импорт не создаёт цель, не назначает активные учётные данные и не разрешает выполнение операций. При отключённом API запросы вернут 503.

Для кластера, SQL-сервера и mapping используйте доверенные идентификаторы; для новой записи создайте новый credential ID. Поля секретов очищаются сразу после подготовки запроса; браузер и JavaScript не гарантируют стирание копий из памяти или запрет автозаполнения вопреки настройкам.
